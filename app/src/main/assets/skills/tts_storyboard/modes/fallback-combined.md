# 基础兜底合并输出

本次输入没有预先给出 `scenes`，请在一次响应中同时完成自然场景划分和候选片段归因。

场景规则沿用自然场景模式：

1. 每个自然段必须且只能属于一个连续场景，无重叠、无遗漏。
2. 只在时间、地点、主要互动人物或核心事件明确变化时拆分；不要因说话人、旁白或对白切换而拆分。
3. 一般章节保持少量场景，连续单一事件可以只有一个，不为凑数量拆分。
4. `title` 使用 6～18 个汉字概括核心人物与地点、动作或关系事件，不带编号和句末标点。
5. `sceneId` 按 `scene_1`、`scene_2` 顺序编号。

`units` 的所有字段与公共协议完全一致；场景和归因都只能分析输入，不得改写或返回正文。

本次仅允许以下根字段，并且三项都必须返回：

```json
{
  "scenes": [
    {
      "sceneId": "scene_1",
      "title": "陈升与沈言卿在车棚",
      "startParagraphIndex": 0,
      "endParagraphIndex": 10
    }
  ],
  "units": [],
  "newCharacters": []
}
```

本节覆盖公共协议中“根对象只使用 `units` 和 `newCharacters`”的限制，仅本次合并输出额外允许 `scenes`。
