# 演员层：表演指令

当前引擎支持演员层。在场景上下文之上，为 `character` 和 `thought` 生成一句可直接交给演员执行的 `performanceInstruction`。

每个输出 unit 都必须包含 `performanceInstruction` 字符串。启用演员层时，`character` 和 `thought` 必须返回一句简短指导；`narrator` 和 `other` 使用空字符串。

演员层将公共协议中的 unit 对象扩展为以下结构；公共字段保持原义：

```json
{
  "unitId": "输入中的目标 ID",
  "roleType": "character",
  "characterName": "角色名或空字符串",
  "characterId": 0,
  "speakerGender": "female",
  "status": "unknown",
  "confidence": 0.88,
  "evidence": "前文动作: 角色名",
  "performanceContext": ["对方仍有些不安；说话人想让对方放松下来再继续交流。"],
  "performanceInstruction": "温和笃定地安抚，让对方安心"
}
```

指令聚焦当前这一句怎么说，从以下维度选择最关键的 1～3 项：

- 开口状态：迟疑、急切、强撑平静、话到嘴边又收住。
- 情绪强度与变化：克制、逐渐放松、后半句渐弱、短暂失控后收住。
- 节奏与停顿：短促、放慢、断续、关键词前留出停顿。
- 气息与声音状态：刚哭过、轻微抽噎、气息不稳、压低声音。
- 交流目的：试探、安抚、掩饰、解释、警告、撒娇、逞强。

把场景事实转换成简短、可听见的表演动作。指令应贴合当前人物和目标台词，强度以原文证据为准；普通对话保持自然，明确出现哭泣、喘息、颤抖等状态时才写相应表现。

演员层的作用是保证每句人物声音都有明确演法，不能把普通问答、日常陈述或短句留成裸正文。没有强烈情绪时，写清交流方式和目的，例如“自然询问，直接但不施压”“温和笃定地安抚，让对方安心”“平静说明，重点处稍作强调”；不要为了填字段虚构哭腔、愤怒或其它原文没有的强烈表现。

每句 4～40 个字符，不加入新台词、拟声词或正文内容，不指定供应商参数。不要重复台词中已经直接表达的结巴、省略或停顿，不要只写泛化的“语速适中”“语气自然”；中性对白也必须补充交流目的或关系姿态。`narrator` 和 `other` 返回空字符串。

演员层输出示例字段：

```json
"performanceInstruction": "刚哭过，开口迟疑，后半句逐渐变轻"
```
